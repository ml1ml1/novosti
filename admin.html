Прямая публикация в GitHub Pages (Чтобы видели все читатели)

Когда вы нажимаете «Опубликовать на сайт (GitHub)», админка через официальный GitHub REST API автоматически обновляет файл db.json прямо в вашем репозитории. Все пользователи, заходящие на ваш сайт по ссылке, сразу видят новые статьи и изменения.

Токен сохраняется исключительно в localStorage вашего браузера и никогда не попадает в публичный код сайта.
